# Weather App

A modern weather application built with **Flutter**. The app is designed to provide users with detailed and easy-to-read weather information for selected locations, including current conditions, hourly and daily forecasts, air quality, and additional weather data.

## Features

### Current Weather

* View current weather conditions for the selected location.
* Display current temperature and weather conditions.
* Check the feels-like temperature.
* View wind speed, humidity, and atmospheric pressure.

### Hourly Forecast

* View detailed weather conditions for the upcoming hours.
* Check hourly temperature changes.
* View weather conditions and precipitation probability.
* Check wind speed and direction.
* Access a dedicated detailed hourly forecast screen.

### 7-Day Forecast

* View the weather forecast for the upcoming seven days.
* Check minimum and maximum temperatures for each day.
* View expected weather conditions.
* Compare daily temperature ranges using visual indicators.

### Location Search

* Search for cities and locations.
* Change the currently selected location.
* Store the selected location locally.
* Automatically display weather data for the selected place.

### Sunrise & Sunset

* View sunrise and sunset times.
* Visualize the daily sun cycle.
* Quickly check the length and current stage of the day.

### Air Quality

* View current air quality information.
* Check the air quality index.
* Display air quality using a simple visual indicator.

### Detailed Forecast

* Select individual forecast days.
* Browse hourly weather conditions for a selected day.
* View temperature, precipitation, and wind information in a structured format.

## Technologies

The application was developed using:

* Flutter
* Dart
* Provider for state management
* Hive for local data storage
* REST APIs for weather and location data
* Material Design

## Project Goals

The project was created to combine a practical weather application with modern mobile application development using Flutter.

The main focus of the project is:

* Clean and intuitive user interface.
* Integration with external REST APIs.
* Processing and presenting weather data.
* Local data persistence.
* State management.
* Reusable custom widgets.
* Responsive mobile layouts.
* Smooth navigation and animations.
* Modular and maintainable application structure.
